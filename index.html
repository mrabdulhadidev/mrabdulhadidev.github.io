About

The full story — how I got here, what I've built, and where I'm headed.

I'm a self-taught developer based in Faisalabad, Pakistan. There was no single moment where I decided to become a programmer — it built up gradually, the way most self-taught skills do: one small script that worked, then a slightly bigger one, then a full app I could actually put in front of someone.

Somewhere in that process I started teaching what I was learning, almost by accident — explaining a concept to someone else forced me to actually understand it properly myself. That habit turned into Python for AI Engineers, a complete beginner-to-intermediate book written for people with no programming background at all. My mission with it is simple: make world-class technology education available to every student, in plain language, without gatekeeping.

Building real things

Writing about programming is one thing; shipping software people actually use is another. Elitra was the biggest test of that — a five-platform food delivery marketplace with four different user roles, built solo from the database up, load-tested to make sure it could actually hold up under real traffic instead of just looking good in a demo.

Elice pushed in a different direction: could a finance app run its AI assistant completely offline, with zero dependency on the internet or a cloud API? Getting a 1.5-billion-parameter model to run smoothly on-device took real trial and error, including redesigning the extraction pipeline in native Kotlin after the first approach hit a wall.

MCF came from something more personal — a working cattle farm that needed one clear dashboard instead of scattered paper records. And the Telegram bot was where a lot of this started: a small, complete project built end to end, on Termux, with nothing but a phone.

What I'm exploring now

Outside of client work, I'm interested in programming languages and compiler design — specifically, what better foundations for AI development might look like at the language level. This is a personal, long-term interest I'm still exploring, not a shipped project.

2025 — 2026

Elitra

A restaurant and home-kitchen marketplace needed one platform that could handle four different user types — customers, restaurants, home kitchens, and admins — without the system falling over under real traffic.

Built the full order lifecycle: cart, checkout, manual payment verification, live status tracking, and a disputes-and-refunds flow with a per-customer refund wallet. Real-time chat and order sync run through Supabase with sub-100ms broadcast latency. Also designed the full brand identity — logo, type system, color palette.

StackFlutter 3.10.6, Neon PostgreSQL, Supabase (Auth, Storage, Realtime), GitHub Actions
RolesCustomer, Restaurant, Home Kitchen, Administrator
Scale47 screens, 19 database tables, load-tested to 10,000+ concurrent users
SecurityTLS 1.2+, automated backups, full audit logging, GDPR-compliant handling
github.com/teamchama23-sys/Elitra.pro

Elice

A personal and business finance app that needed to work with zero internet connection — including the AI assistant.

Runs a quantized 1.5-billion-parameter language model (Qwen2.5-1.5B-Instruct) fully on-device via llama.cpp. Handles CSV and bank statement import, expense and investment tracking, loan/EMI tracking, savings goals, a business ledger, and simplified tax estimation.

StackFlutter (Dart), SQLite (sqflite), fllama (llama.cpp), Qwen2.5-1.5B-Instruct (GGUF, Q4_K_M)
Runs onFully offline, on-device — no internet required for any feature
Data7 local SQLite tables with schema versioning across app updates
ModulesExpenses, investments, loans/EMI, savings goals, business ledger, tax estimation
github.com/teamchama23-sys/Elice
